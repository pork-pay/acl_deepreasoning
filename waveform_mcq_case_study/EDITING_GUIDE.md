# Local editing guide

The bundle now contains the original raw records, analysis-ready arrays, exact perturbation code, and a relative-path renderer. You can change layout and style without touching `/gruntdata`.

## Waveform files

### Case 1: PR prolongation

```text
waveforms/case_01_pr_prolongation/
  source_wfdb/00439_hr.hea
  source_wfdb/00439_hr.dat
  signal_original.npz
  signal_perturbed.npz
  signal_original.csv.gz
  signal_perturbed.csv.gz
```

### Case 2: heart-rate reduction

```text
waveforms/case_02_rate_slowing/
  source_wfdb/00774_hr.hea
  source_wfdb/00774_hr.dat
  signal_original.npz
  signal_perturbed.npz
  signal_original.csv.gz
  signal_perturbed.csv.gz
```

Each NPZ contains:

```python
signal      # float array, shape (5000, 12), mV
fs          # 500 Hz
lead_names  # I, II, III, AVR, AVL, AVF, V1–V6
```

Each compressed CSV contains `time_s` followed by the 12 leads.

## Reproduce the waveform edits

Run commands from this bundle directory.

```bash
python methods/waveform_synthesis.py \
  --operator pr \
  --input waveforms/case_01_pr_prolongation/signal_original.npz \
  --output editable_outputs/case01_reproduced_pr300.npz \
  --target 300

python methods/waveform_synthesis.py \
  --operator rate \
  --input waveforms/case_02_rate_slowing/signal_original.npz \
  --output editable_outputs/case02_reproduced_hr48.npz \
  --target 48
```

The bundled reproductions match the saved perturbed arrays exactly (`max_abs_diff = 0`). Each command also writes an operator audit JSON.

## Re-render with custom layout

```bash
python methods/render_editable.py \
  --original waveforms/case_01_pr_prolongation/signal_original.npz \
  --perturbed editable_outputs/case01_reproduced_pr300.npz \
  --output editable_outputs/my_case01 \
  --title 'PR-interval prolongation' \
  --change-label 'PR 130 to 298 ms' \
  --dpi 300
```

Useful layout flags:

```text
--fig-width / --fig-height     overall paper dimensions in inches
--dpi                          PNG resolution
--y-limit                      symmetric ECG amplitude range in mV
--line-width                   ECG trace thickness
--grid-alpha                   grid opacity
--hspace / --wspace            gaps between leads
--lead-box-aspect              individual lead aspect ratio
--rhythm-box-aspect            rhythm-strip aspect ratio
--no-rhythm                    omit the lead-II rhythm strip
```

Colors and typography are grouped in the `STYLE` dictionary at the top of `methods/render_editable.py`.

Ready-to-edit examples are in `editable_outputs/`:

- `case01_custom_render.{png,pdf}`
- `case02_custom_render.{png,pdf}`

## Edit the complete case-study figure

The figure combining waveform pairs, MCQ options, and CoT acceptance is generated by:

```bash
python end_to_end/render_end_to_end_figure.py
```

Main editable elements are the `CASES` and `COLORS` dictionaries and the `draw_case_text()` function.

Outputs:

- `end_to_end/paper_end_to_end_waveform_mcq_cot.pdf`
- `end_to_end/paper_end_to_end_waveform_mcq_cot.png`

## Re-run CoT synthesis

See `end_to_end/END_TO_END_WAVEFORM_MCQ_COT_PIPELINE.md` for the exact multimodal prompt, Qwen3.8 request body, acceptance rules, and command. API credentials are intentionally not stored in this bundle.

## Important scientific constraints

- Do not edit waveform pixels in an image editor; modify the NPZ and re-render.
- Preserve 25 mm/s and 10 mm/mV calibration when changing figure dimensions.
- Re-run measurements whenever the waveform changes.
- Do not place the diagnosis or correct option on the model-input ECG.
- These are automatically closed-loop-verified counterfactual labels, not cardiologist-adjudicated clinical gold labels.
